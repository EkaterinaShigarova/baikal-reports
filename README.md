# Baikal LLM Wiki

Университетский проект экологического мониторинга озера Байкал и Байкальской природной территории по государственным докладам. Целевой период — **2003–2026**, фактическое покрытие перечислено в [SOURCES.md](SOURCES.md). Непроверенные годы не подменяются вымышленными документами.

Система загружает PDF, сохраняет неизменяемые оригиналы, обрабатывает страницы с возобновлением, создаёт постоянную связанную Markdown Wiki и показывает проверенные данные в локальном веб-приложении. Базовый режим бесплатен и не требует LLM API. [Методика Karpathy и границы реализации](docs/METHODOLOGY.md).

## Что уже работает

- Обнаружение PDF в публичной папке Google Drive, проверка официальных каталогов и регистрация дополнительных официальных PDF.
- Потоковая загрузка, SHA256, проверка размера/формата, хранение версий, обработка каждой страницы независимо.
- Текст, заголовки и блоки, таблицы PyMuPDF/pdfplumber, кандидаты продолжений таблиц, изображения, подписи и превью. OCR Tesseract rus+eng для страниц с плохим текстовым слоем.
- SQLite FTS для поиска по страницам, постоянные Wiki-страницы источников, тем и сущностей; индекс, журнал, query с сохранением, lint.
- Набор **49 реальных значений**, сверенных AI-агентом с текстом и рендерами таблиц доклада 2018 года; отдельные статусы происхождения и сопоставимости.
- Веб-приложение: обзор, Wiki, поиск, фильтры, интерактивные графики, сравнение годов, таблицы, просмотр страниц и ссылки на оригиналы.
- Необязательный LLM-синтез ограниченных пакетов доказательств с проверкой цитат и сохранением черновиков.

Полный фактический отчёт о выполнении: [PROGRESS.md](PROGRESS.md). Это исследовательский инструмент, а не аттестованная система государственного мониторинга. Автоматически извлечённые таблицы и числа требуют проверки; их качество не объявляется идеальным.

## Быстрый старт в Visual Studio Code

### 1. Получить проект

Установите Python 3.11 или новее, Git и VS Code с расширением Python. Клонируйте репозиторий и откройте папку в VS Code:

```bash
git clone https://github.com/EkaterinaShigarova/baikal-reports.git
cd baikal-reports
git switch feat/baikal-llm-wiki
code .
```

После слияния Pull Request переключаться на отдельную ветку не требуется.

### 2. Создать окружение

В терминале VS Code (меню «Терминал → Создать терминал»):

```bash
python -m venv .venv
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Если политика PowerShell не позволяет активацию, используйте `.\.venv\Scripts\python.exe` вместо `python`; изменение политики не обязательно. Выберите созданное окружение через команду VS Code **Python: Select Interpreter**.

```bash
python -m pip install -r requirements.lock -e ".[test]"
python -m unittest discover -s tests -v
python -m baikal build
python -m baikal serve
```

Откройте адрес, напечатанный сервером, в браузере на своём компьютере (по умолчанию порт 8000). Остановка — `Ctrl+C`. Обзор, Wiki и компактный набор данных доступны из Git сразу; полнотекстовый поиск и просмотр PDF наполняются после ingest. Большие PDF в Git отсутствуют.

### 3. OCR и документы

Установите **Tesseract OCR 5**: Linux — пакет `tesseract-ocr`, macOS — `brew install tesseract`, Windows — сборка Tesseract с добавлением исполняемого файла в PATH. Затем:

```bash
python scripts/setup_ocr.py
python -m baikal discover --official
python -m baikal ingest --source drive-1QKhC57MB-qveIXhYWKGfSOkTmzdFw_mJ --workers 2
```

Первый пример обрабатывает весь доклад за 2018 год, 342 страницы. Все найденные документы:

```bash
python -m baikal ingest --workers 2
```

Нужны свободный диск и время: оригинальная коллекция близка к 1 ГБ; изображения, превью и промежуточные результаты увеличивают расход. Рекомендуется не менее 10 ГБ свободного места и 4 ГБ RAM. Большие сканы с OCR могут обрабатываться значительно дольше текстовых PDF. Не запускать два ingest одновременно в одной рабочей копии.

После прерывания повторите ту же команду: завершённые страницы с совместимой версией извлекателя сохраняются. `--limit-pages 10` подходит для пробного запуска и отмечается как частичная обработка. `--retry-errors` повторяет ошибки OCR. Установка языковых моделей сохраняет TLS и проверяет SHA256.

## Обновления и Wiki

```bash
python -m baikal update --workers 2
python -m baikal status
python -m baikal query "качество воды" --save
python -m baikal lint
python -m baikal export-candidates
```

`export-candidates` сохраняет локальный JSONL всех числовых кандидатов с контекстом в `data/exports/`; неизвестные год, территория и показатель остаются null.

`update` перечитывает папку, добавляет новые документы, обрабатывает изменившиеся и обновляет Wiki/индекс. Для принудительного сравнения содержимого удалённого файла, в том числе изменения при одинаковом размере, используйте `--refresh`: PDF заново скачивается и сравнивается по SHA256, неизменившиеся страницы не пересчитываются. Различные версии исходника остаются на диске по разным хешам.

Для еженедельного запуска на Linux можно добавить в cron команду `cd /путь/baikal-reports && .venv/bin/python -m baikal update >> /путь/baikal-update.log 2>&1`. На Windows аналогичную команду запускает Планировщик заданий. Не планируйте перекрывающиеся запуски.

`wiki/` можно открыть в Obsidian или VS Code. Статьи содержат источники и страницы; `wiki/index.md` — входная точка, `wiki/LOG.md` — журнал. Автоматический ingest обновляет выдержки и связи. Ручные замечания после `<!-- HUMAN NOTES -->` сохраняются. Новые аналитические статьи размещаются в `wiki/syntheses/`. [AGENTS.md](AGENTS.md) описывает правила для AI-агентов.

Оригинальная методика не сводится к RAG: знания сохраняются и изменяются в Wiki, включая результаты запросов. Бесплатный компилятор выдержек не выдаётся за семантический LLM-синтез. Для последнего доступны AI-агент и [настраиваемый локальный/API-режим](docs/LLM.md).

## Официальные источники

`discover --official` проверяет разрешённые официальные каталоги и сохраняет результаты в реестр. Найденная PDF-ссылка — кандидат, не доказательство содержания. После проверки ссылки можно зарегистрировать документ:

```bash
python -m baikal add-source --url 'https://www.mnr.gov.ru/ПОДТВЕРЖДЁННЫЙ-ПУТЬ.pdf' --name 'Название с титула' --year 2020
```

Это шаблон, не реальный URL. Далее `ingest --source <выданный-id>`. Подлинность зеркала Google Drive не подтверждается только названием файла или наличием слова «государственный». Необходимо сопоставление с публикацией ведомства. Сетевые ошибки и отсутствие доступа перечислены в SOURCES.md; TLS-проверка не отключается.

## Данные и сопоставимость

CSV и JSON: [datasets/](datasets/README.md). Поля: год наблюдения, показатель, значение, единица, территория, документ, SHA256, страница, цитата, метод, период, статус проверки и сопоставимости. Год публикации/доклада хранится отдельно от года наблюдения.

Проверенные значения перенесены из одного ретроспективного источника. Это не означает, что отдельные доклады за все соответствующие годы уже найдены. Ряды из разных таблиц и методик автоматически не склеиваются. Столбец confidence описывает уверенность переноса, а не научную достоверность измерения. Кандидаты из других страниц сохраняются локально и не становятся данными графика без рецензирования.

## Структура

```text
baikal/             CLI, загрузка, PDF/OCR, SQLite, Wiki, API
web/                локальный веб-интерфейс без CDN
config/             каталог источников и схема Wiki
datasets/           компактные проверенные CSV/JSON
wiki/               источники, темы, сущности, синтез, запросы, журнал
data/raw/           неизменяемые PDF по SHA256 (не в Git)
data/processed/     страницы, таблицы, изображения, QA (не в Git)
data/baikal.sqlite  полнотекстовый индекс (не в Git)
tests/              тесты контрактов и поведения
```

## Ограничения

Карты, схемы и графики сохраняются как изображения с подписями и статусом human_review. Автоматическая достоверная оцифровка кривых не реализована. Сложные/многостраничные таблицы сохраняются и связываются как кандидаты; без проверки геометрии и структуры их нельзя считать полностью восстановленными. Платный LLM не устраняет эти ограничения. Официальная подлинность и покрытие всех лет остаются отдельными задачами.

Сервер предназначен для локальной работы. Публикация в Интернет потребует отдельной настройки доступа. Секреты задаются переменными окружения; .env, PDF и data/ исключены из Git. Исходные PDF не изменяются.
