# Baikal LLM Wiki

Проект экологического мониторинга Байкальской природной территории и озера Байкал на основе официальных государственных докладов за 2003–2026 годы.

## Цель

Разработать систему обработки государственных докладов, построения базы знаний по методике Andrej Karpathy LLM Wiki, извлечения экологических показателей и визуализации данных.

## Архитектура

- Google Drive — исходные PDF-документы.
- GitHub — исходный код и результаты разработки.
- Codex — разработка и автоматизация обработки.
- LLM Wiki — структурированная база знаний.
- Dashboard — визуализация экологических данных.

## Статус

Проект находится на этапе первоначальной разработки.
