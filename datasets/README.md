# Данные и границы достоверности

`observations.json` и CSV содержат 49 реальных значений из доклада за 2018 год: 42 значения шести рядов выбросов за 2012–2018 годы (табл. 1.3.1.2.1, PDF стр. 168) и 7 средних концентраций несульфатной серы (табл. 1.1.1.2.1, PDF стр. 19). Значения сверены AI-агентом с текстом и изображением таблиц. Это проверка переноса из документа, не экспертная сертификация экологической статистики и не независимое подтверждение подлинности зеркала.

Разрешено сравнение выбросов внутри одной ретроспективной таблицы с общим территориальным охватом, единицами и периодом. Для концентраций серы сопоставимость выборки по годам не подтверждена, поэтому график изменений запрещён. Числа за 2012–2017 годы здесь происходят из доклада 2018 года и не означают, что доклады за эти годы уже загружены.

`confidence` — оценка уверенности в правильности переноса, не статистическая вероятность. `quote` для ручной сверки может объединять заголовок/строку/ячейку; `page` и `table` позволяют проверить расположение. Исходные значения не округляются. Несоответствия суммы компонентов итогу не исправляются автоматически.

Все остальные обнаруженные числа находятся в локальных JSON страниц со статусом candidate; они не попадают в аналитические графики автоматически. `wiki_evidence.json` содержит короткие выдержки для обновления статей. Полные постраничные результаты и SQLite находятся в ignored data/.
