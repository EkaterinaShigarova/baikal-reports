# Полнота реестра авандельты и независимые сравнения

23.10.2026. Продолжение от `c46e1d1`; действующая статья и экологические наблюдения не изменены. Это воспроизводимая программная и неэкспертная содержательная проверка, **не научная рецензия специалиста**.

## Результат и границы

Создано 27 карточек: семь прежних сохранены без изменений внутри `legacy_record`, добавлено 20. Они представляют 23 из 26 содержательных предложений статьи — **88,46% предложений**, ранее три из 26. Это не доля проверенных научных фактов: одно предложение может содержать несколько тезисов, а карточка — методическое ограничение или описание состояния проекта. Полная семантическая атомизация не установлена. Три предложения явно отложены, а девять карточек имеют признаки, пригодные для текущего сопоставления.

Читайте [реестр v2](../datasets/selenga_claim_registry_v2.json) вместе с [содержательными поправками статусов](../datasets/selenga_coverage_audit.json) и [отчётом](../datasets/coverage_evaluation.json). В неизменном входном снимке 15 отметок `source_checked_non_expert`. После проверки U01 одна понижена: **эффективно 14** карточек фиксируют сверенные сообщения источников. Заголовки подтверждают различие сред, но не всю составную методическую фразу U01. Ни номинальная, ни эффективная отметка не подтверждает истинность спорного измерения, официальную подлинность зеркала или экспертную проверку. U01 не была полномочием сопоставления, поэтому понижение не меняет экспериментальные решения.

Каждая карточка привязана к точным позициям и тексту статьи, версии PDF, физической странице, цитате и статусу. Неизвестные годы публикации/метаданные остаются `null`. Контекстные ссылки методических карточек не выдаются за прямое доказательство всей фразы. Старый реестр, отчёты и воспроизводимость прежних экспериментов сохранены.

## Что отсутствует и требует уточнения

- **U23:** требование баланса поступления, осаждения и переноса — нужна отдельная методическая библиография. Оно проинвентаризировано, но не превращено в подтверждённый экологический факт.
- **U24:** отсутствие новых рядов и непроверенная сопоставимость станций/методик — нужен реестр состояния данных, а не фиктивный показатель природы.
- **U26:** отсутствие прямого преобразования речного выноса в характеристику грунтовой воды — нужно описание модели, размерностей и допущений.
- **U25 представлено, но не подтверждено в заявленной области:** фраза статьи ссылается на отдельный набор речного выноса за 2024–2025. В `datasets/observations.json` есть другие притоки, но нет территории Селенги. Следует редакционно уточнить область ссылки; действующая статья автоматически не исправлялась.
- **U17:** связь с предыдущей визуальной сверкой таблицы обозначена как прежний аудит, а не новая проверка изображения.

Остальные представленные предложения также могут содержать неразделённые атомарные тезисы. Список точных фраз и их состояний приведён ниже; процент охвата нельзя использовать как разрешение объявить произвольный факт новым.

## Два разных вопроса

**A — отношение к одной записи.** Программа сравнивает объект, показатель, статистический тип, единицу, территорию, период, тип сообщения, атрибуцию и область сводки. Среднее не равно максимуму; другой год/район не становится конфликтом; прогноз не превращается в наблюдение. Прочерк — неизвестное значение. Обычное различие чисел означает потенциальный конфликт для проверки, а не доказанное противоречие.

**B — отсутствие во всей статье.** Даже отсутствие совпадений со всеми девятью пригодными карточками даёт `unknown_requires_full_article_review`. Этот результат не меняется от заявленных 100% охвата. Положительное присутствие требует совпадения признаков либо отдельной смысловой сверки по хешам факта и карточки. Новизна требует отдельной содержательной сверки **всей** версии статьи для **конкретного** факта, включая три отложенных предложения. Такой сертификат не является редакционным одобрением или разрешением публикации.

[Контролируемый словарь](../datasets/selenga_term_vocabulary.json) содержит только ё/е в названии растворённого кислорода и `мг/дм3`/`мг/дм³`. Это одна единица в разной типографике, без пересчёта значений. Широкие синонимы, преобразование процентов осадка в концентрацию воды и числовые пересчёты не реализованы. Извлечение правильных признаков из произвольного PDF пока требует отдельного контроля.

## Два неопубликованных кандидата

После отдельной сверки всех 26 предложений установлено отсутствие двух деталей одной съёмки сентября 2019 из PDF31: **12 проб** и **диапазон глубин 23–58 м**. Это отобранные и сверенные сведения источника, **не новые факты, сгенерированные или обнаруженные Qwen**. Разбивка проб по средам неизвестна: нельзя писать «12 проб каждой среды». Диапазон не средняя глубина.

Они сохранены как два доказательных кандидата в локальном пакете `data/wiki_updates/coverage_candidates/6031cdc119d96f595ae1cd08a425c12edaf93981228733090193e9fc0566d487.json`. Для каждого в публичном отчёте есть факт-ID, источник, хеш, цитата в закреплённом наборе, точная версия статьи и причина отсутствия. Сохранён полный предшествующий текст статьи вместе с областью ручных заметок. Это две детали одного события, не два независимых наблюдения. Редакционного одобрения нет; статьи и 168 наблюдений не менялись.

Кандидаты пригодны для **последующей редакционной проверки** только в этой версионной области и с указанными ограничениями. Программа не может выпускать такие пакеты из одного отсутствия совпадения или общего процента охвата. Общий механизм автоматического обнаружения и публикации нового знания не объявляется готовым.

## Источники и воспроизведение

Реестр статьи использует три доклада и четыре физические страницы: [2015, PDF26](../wiki/sources/drive-1FFG7dMsfKpCRp3yWVm8m2C9vjxK8ATab.md#page-26), [2019, PDF31](../wiki/sources/drive-1RWGLrOzFO32Jxrlv-B2n_PafSFoRVySn.md#page-31), [PDF32](../wiki/sources/drive-1RWGLrOzFO32Jxrlv-B2n_PafSFoRVySn.md#page-32), [2022, PDF40](../wiki/sources/drive-1oYm8VhJ3_eRNdxbrGfLXhf6_vI6s6SJq.md#page-40). Независимые контроли добавляют [2018, PDF112](../wiki/sources/drive-1QKhC57MB-qveIXhYWKGfSOkTmzdFw_mJ.md#page-112) и [2020, PDF13](../wiki/sources/drive-1ScikzOKs0VW7ZZS1XWKyoOfcHeYklUEP.md#page-13). Итого пять документов/шесть страниц. Все цитаты проверены по существующим checkpoint; готовые PDF/OCR не обрабатывались. Подлинность транспортных зеркал не повышена автоматически.

В установленном Python-окружении, из корня проекта:

```bash
python scripts/check_coverage_report.py --require-local
python -m unittest discover -s tests -v
python -m baikal lint
python scripts/check_scientific_review.py --require-local
python scripts/check_encyclopedia.py --require-local
python scripts/verify_evidence.py
```

Без локальных страниц/ответов доступна `python scripts/check_coverage_report.py`: проверяются публичные привязки, текущие входы и решения, а не наличие исходных файлов. Результат отдельно показывает число действительно прочитанных локальных модельных ответов. Ключ `--require-local` требует эти файлы. Это различие проверено в изолированной копии без `data/`.

`python scripts/evaluate_coverage.py --check --require-local` воспроизводит **номинальный входной снимок**: 15 исходных статусов до понижения U01. Для эффективных 14 нужен `check_coverage_report.py`, применяющий отдельную аннотацию. `--help` показывает параметры ограниченного опыта; повторная генерация не нужна для проверки отчёта. Один использованный слот блокируется до старта runtime. Первые входы и эталоны не изменяются после опыта. Сырые ответы, журналы, веса и архивы остаются в исключённой из Git папке `data/`.

Далее нужны атомизация составных фраз, разбор трёх отложенных пунктов и U25, редакционная оценка двух кандидатов и более широкий отложенный набор смысловых проверок. Экспертная оценка методик и подлинности источников остаётся отдельной задачей.
