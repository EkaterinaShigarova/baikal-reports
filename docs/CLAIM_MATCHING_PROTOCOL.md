# Протокол: реестр утверждений и ограниченное сравнение

23.10.2026, исходный commit 3ce5604. Критерии и ожидаемые решения фиксируются до генераций. Это автоматизированная содержательная сверка, не экспертиза специалистом. Никакой публикации в Wiki/observations.

## Объект и данные

Одна существующая статья: `wiki/syntheses/selenga-sediments.md`. Частичный реестр `datasets/selenga_claim_registry.json` содержит семь утверждений о сводке ароматических загрязнителей 2015 года: пять приписанных прозе/таблице максимумов и две качественные оценки. Для каждого сохранены объект, показатель, число либо качественная оценка, статистика, единица либо null для качественной оценки, территория, период, тип сообщения, роль источника, точный фрагмент/позиция статьи, SHA256 статьи, ID/SHA256/PDF 26/цитаты источника и статус сверки. Публикация неизвестна, зеркало mirror_unverified. Территория максимумов здесь — область отчётной сводки, не придуманная станция или выборка; это ограничение явно сохранено.

Два прежних факта — средние БП 2,1 и ПАУ 36,9 нг/г с.о. по всему полигону за 2015 — используются по старым fact-ID и SHA256 без нового извлечения. Третий прежний факт 61,7 по протоке сохранён в исходном пакете и не включён в этот набор ради равного числа примеров каждого класса. Новые экологические значения не создаются.

## Набор до запуска

`datasets/claim_comparison_benchmark.json`: восемь **сравнений**, по два на класс. Ожидаемые решения основаны на источнике и точной версии статьи, не на ошибочных ответах модели.

| ID | Ожидается | Основание |
| --- | --- | --- |
| A1 | already_present | Атрибутированный таблице максимум БП 7,9 уже приведён в статье |
| A2 | already_present | «Фоновое значение» источника и «фоновый уровень» статьи — одна качественная оценка |
| N1 | new_detail | Среднее БП 2,1 отсутствует в полной статье; максимум/фон его не выражают |
| N2 | new_detail | Среднее ПАУ 36,9 отсутствует в полной статье; максимум/классификация его не выражают |
| C1 | contradiction | Сообщение таблицы БП 7,9 противопоставляется конкретному сообщению прозы БП 61,8 |
| C2 | contradiction | Сообщение таблицы по канцерогенным аренам 61,8 противопоставляется прозе 7,9 |
| I1 | insufficient_evidence | Явно обозначенная неполная проекция настоящего фрагмента: период не передан; нельзя подставить год доклада |
| I2 | insufficient_evidence | Нельзя признать табличный максимум истинным без атрибуции при открытом расхождении источника |

**C1/C2 проверяют реальное расхождение атрибуции внутри источника, уже описанное статьёй.** Это отношение к указанному противоположному утверждению, не обнаружение нового противоречия Wiki, не два независимых экологических события и не доказательство разных истинных измерений. A1/C1 используют один исходный табличный факт при разных явно заданных областях сравнения. В полной области уже сохранённый вариант имеет приоритет над сигналом конфликта. I1 — контроль пропущенных метаданных, а не утверждение, что полный доклад не датирует наблюдение. I2 проверяет границу знания, а не подставляет ложное измерение. Эти ограничения сохранять в отчёте и итоговых числах.

## Механизм и лимит

1. Строго сравнить объект/показатель/единицу/территорию/период/статистику/тип сообщения/область сводки. Похожие слова не означают совпадения. Среднее не максимум, план/прогноз не наблюдение. Произвольное различие чисел ещё не доказывает противоречия: автоматический вывод ограничен прежними документированными парами.
2. Отсутствие точного совпадения возвращает `llm_required`, не new_detail. Неизвестные существенные признаки и неразрешимый выбор истинного значения отклоняются без модели.
3. Маршрутизация до запуска: A1/C1/C2/I1/I2 — пять структурных решений; A2/N1/N2 — не более **трёх реальных запросов Qwen**, один факт за запрос. Модель получает только признаки этого факта, точные компактные доказательства (для таблицы — проверенные подпись, строка, заголовок, ячейка/координаты), релевантные содержательные утверждения статьи и открытые вопросы. Эталоны/причины ожидаемых меток не передаются. Заголовки статьи как доказательства отсутствуют в допустимых ID.
4. Прежние Qwen2.5-7B-Instruct Q4_K_M и llama.cpp, SHA256/Apache-2.0 проверяются; CPU 4 потока, контекст 8192, batch 256, GPU 0, temperature=0, max_tokens=512, timeout=600 с, только loopback. До каждой попытки нативный бюджет и дополнительный предел 3500 входных токенов; файл слота создаётся до HTTP. Невалидный/неверный ответ не повторять, свободный слот не переносить. Модель/данные не скачивать и не извлекать повторно.
5. Ответ содержит только собственный fact-ID, класс, код отношения, ID утверждений и сохранённых конфликтов. Переписанные числа/годы/единицы/источники, неизвестные или повторные ID и исчезновение ограничений запрещены. JSON/ID-корректность не означает смыслового успеха.

## Критерии оценки

- Отдельно считать пять структурных и до трёх модельных решений. После генераций проверить правильность категории и опоры, не только формат. Ошибка/усечение/отсутствие ответа — не успех.
- Подтвердить, что A2 не объявлена новой из-за перефразирования; средние N1/N2 не перепутаны с максимумами; источник/статья и типы сообщения не смешаны. Сохранить обе противоречащие пары и неизвестную публикацию.
- Смысловая сверка N1/N2 включает полную неизменную статью, не только частичный реестр. Допустимый результат — **кандидат для редакционной проверки**, не автоматически установленная новизна или разрешение публикации. Сохранить его с исходными цитатами/фактом и полной предыдущей версией статьи вне действующей Wiki.
- Сравнение с прежним подходом возможно только для N1/N2: тогда оба insufficient_evidence и неверны; третий факт не тестируется. Для остальных шести прежних ответов нет. Не заявлять улучшение на всём сбалансированном наборе против отсутствовавшего baseline.
- Зафиксировать токены, время и RSS; один узкий, частично зависимый набор не оценивает общую точность модели или всех статей. Повторные прогоны под эталон запрещены.
- Сохранить прежние 22 статьи, 168 наблюдений, 3878 checkpoint, SHA256 11 PDF и научные реестры. Тесты, Wiki lint, проверки цитат/реестра; сайт и OCR не затрагиваются.
