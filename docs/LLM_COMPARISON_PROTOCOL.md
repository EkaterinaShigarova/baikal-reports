# Протокол сравнения LLM v1/v2

Зафиксирован до двух генераций v2, исходный commit 903a62b. Один ответ на каждый случай, без скрытых повторов или исправления вывода. Та же Qwen2.5-1.5B Q4_K_M, SHA256, runtime AVX2, temperature 0, четыре потока, контекст 8192 и max_tokens 1800. Платных API и публикации нет.

Сравниваются восемь прежних критериев: понимание, новизна, тема, содержательное дополнение, цитаты, вымышленные значения, противоречия, ограничения. Отдельные счётчики: реальные ответы; прошедшие программные проверки; пригодные после смысловой сверки; ошибки цитирования; ложная новизна; новые поддержанные детали; пропущенные противоречия. Пустой корректный ответ не считается содержательным успехом.

Ожидания проверки, которые не добавляются в модельный промпт:
- Осётр: выделить 1029 тыс. рыб средней навеской 3,0 г как часть выпуска 2016, отличить от общего выпуска 1044 тыс., не выводить выживаемость. Общая производственная цепочка уже известна.
- Авандельта: не называть заголовок новым фактом; сохранить известное различие порядка максимумов БП/канцерогенов между прозой и таблицей 2015 года, не выбирать исправленный вариант; не смешивать среды/территории.

v2 меняет одновременно формат и отбор входов: фрагменты с идентификаторами, контекст Wiki отдельно от доказательств, только целевая тема, явное различие new_detail/already_present/uncertain и отдельные unsupported_candidates. В осетровом случае исключается смешанное окно 2024/67, из которого нельзя взять связный короткий текст об осетре без восстановления колонок. Оно сохраняется в старом пакете и журнале исключений; сведения 2024 остаются в контексте статьи, но не могут использоваться как новые доказательства. Для 2016 исключается график; для 2015 разделены проза и полная таблица без изменения символов. Это целевая редакционная подготовка, не автоматическое исправление PDF и не слепой тест. Её результат нельзя приписывать только новому промпту или способности модели.

Цитаты v2 разрешаются программно по ID в пределах immutable-пакета, повторно сверяются с кешем и SHA256. Поэтому доля точных подставленных цитат не сравнивается с долей дословного копирования v1 как улучшение памяти модели. Неизвестный ID, источник из Wiki, изменённый пакет, заголовок вместо факта, очевидный повтор под видом new_detail, пустые ограничения и числа вне выбранных фрагментов отклоняются. Семантическая поддержка, единицы, область действия и полнота сохранения конфликта проверяются отдельно, даже после успешной программной валидации. Все черновики требуют редакционного решения.

Если оба ответа снова отклонены, размер модели остаётся гипотезой: ошибки от инфраструктуры/отбора/правил не доказывают недостаточность 1.5B. Следующий кандидат оценивается по лицензии, размеру и ресурсам без скачивания или подмены в текущем опыте. Для вывода нужен отдельный сравнительный тест на одинаковых входах.
