# Протокол полноты одной статьи и независимых сравнений

23.10.2026, исходный commit c46e1d1. До проверки зафиксированы источники, точная версия статьи, новые примеры и ожидаемые отношения. Старые семь записей/восемь сравнений и прежние три запроса сохраняются, не повторяются.

## Полнота без ложного подтверждения

Статья `wiki/syntheses/selenga-sediments.md` содержит 26 содержательных предложений после исключения заголовков, навигации и баннера проверки. Ручные заметки сейчас пусты; их появление требует новой проверки. Предложение может содержать несколько атомарных тезисов, поэтому это **счёт предложений, не гарантия полной семантической атомизации**.

Реестр v2 сохраняет семь исходных записей и добавляет 20 карточек: 27 карточек представляют 23/26 предложений (88,46%). Прежний реестр представлял три предложения. 15 карточек описывают сверенные сообщения источников, остальные — ограничения, интерпретации и состояние проекта с отдельными статусами; не превращать их в подтверждённые измерения. Только девять карточек имеют пригодные для текущего сопоставления признаки. Остальные описаны явно, но не являются полномочием автоматически сопоставлять экологические числа.

U23 (требование балансов), U24 (отсутствие рядов/непроверенные методики), U26 (невозможность прямого преобразования речного выноса и грунтовой воды) остаются в инвентаризации как отложенные. Нет доказательства полной семантической полноты, `absence_authorized=false`. Ссылка U25 на речной вынос требует уточнения области: в 168 observations за 2024–2025 нет территорий Селенги, хотя есть другие притоки. Статья не редактируется автоматически.

## Два независимых вопроса

A: отношение одного факта к конкретной записи: тот же факт, несовпадение статистики/периода/территории/единиц/типа сообщения, арифметическое расхождение, недостаточность, смысловой разбор. B: присутствие во всей статье. Совпадение с проверенной карточкой показывает присутствие в точном фрагменте; отсутствие совпадения **всегда** требует отдельной проверки полной статьи, независимо от процента инвентаризации.

Новая карточка из источника не должна переносить в статью числа, которых в ней нет: статья говорит об одной съёмке 2019 года, но не содержит 12 проб и глубин 23–58 м из источника. Эти две детали — кандидаты только после отдельной факт- и версионно-связанной проверки отсутствия. Разбивка 12 проб по средам неизвестна; не утверждать по 12 проб каждого типа. Кандидаты не публикуются и не добавляются в observations.

## Лимит и оценка

Сначала сравнить все случаи программно. Только V07 требует смысла: не более **одного** реального запроса установленной Qwen2.5-7B-Instruct Q4_K_M. Один факт, одна точная статья-фраза, собственная цитата 2019 года, без полного текста статьи и прошлых примеров. Ответ: неизменные fact-ID/target-ID и одно отношение entails/not_entailed/uncertain, без второго дублирующего кода или свободных научных утверждений. Это не ослабляет проверки значений/источников: они read-only, версия/цитата/ID проверяются, итог требует отдельной смысловой сверки.

Прежний llama.cpp, SHA256 весов/runtime, CPU4, контекст8192, batch256, GPU0, temperature0, max_tokens256, timeout600с. Только loopback. Нативный предел 2500 входных токенов и полный резерв ответа до слота; один файл попытки до HTTP, без повторов/ремонта ответа. Если все случаи стали структурно решаемыми, модель не вызывать. Корректный JSON не равен верному смыслу.

Считать программные и модельные решения отдельно. Эталон V07 — entails; неизвестный/неверный ответ не засчитывать. Общие оценки для всех статей из 12 узких примеров не делать. После проверки отдельно показать B без сертификата отсутствия и с настоящей неэкспертной сверкой полной статьи по хешу конкретного факта. Сохранить только неопубликованные доказательные кандидаты, не редакционное одобрение. Проверить 22 статьи, 168 наблюдений, 3878 checkpoint, SHA256 11 PDF и неизменность всех старых реестров/отчётов. Сайт, PDF/OCR и платные API не затрагивать.
