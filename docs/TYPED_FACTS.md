# Типизированные доказательства: экспериментальная версия source-first

Этот режим дополняет [source-first](SOURCE_FIRST.md), сохраняя его строгую границу перед Wiki. Он не заменяет основной обработчик PDF и не изменяет observations. Критерии заданы до запуска в [TYPED_FACTS_PROTOCOL.md](TYPED_FACTS_PROTOCOL.md); результаты — в [LLM_EVALUATION.md](LLM_EVALUATION.md).

Из прежних фрагментов программы сохраняют точные цитаты. Отдельно подготовлено представление только строки 2015 таблицы 1.1.1.3.6: [typed_evidence_2015.json](../datasets/typed_evidence_2015.json). Шесть столбцов сверены с изображением исходной PDF-страницы 26 и прежним checkpoint. Сохранены заголовки, подпись о диапазонах/средних, исходная единица «нг/г с.о.», координаты и исходный текст каждой ячейки. Две версии максимумов не исправлены. Это целевая предварительная подготовка, не самостоятельное открытие противоречия моделью и не научная рецензия.

Модель выбирает первичный фрагмент, при необходимости ячейку/статистику и точную опору года. Годы отчёта/публикации подставляются из реестра отдельно. Год получения икры не используется для датировки выпуска. Статистика ячейки, показатель, территория, единица и год проверяются вместе. Конфликтные максимумы требуют атрибуции прозе/таблице и ссылки на известную неоднозначность.

Сервер применяет JSON schema при декодировании, а программа повторно проверяет поля. Это ограничивает форму ответа. Текст ограничений пишет модель; отсутствующие или ложные ограничения нельзя «починить» автоматически. Факты проходят отдельную сверку со страницей перед следующим запросом. Дополнительные замечания сверки передаются сравнению отдельно, без изменения immutable-факта. Непригодный случай пропускается, не блокируя другой допустимый.

Команды для установленной среды (новый опыт требует собственного обоснованного протокола; повтор текущего без причины не нужен):

```bash
python scripts/evaluate_typed_facts.py --prepare --output data/llm-evaluation/typed-prepared.json
python scripts/evaluate_typed_facts.py --extract --experiment EXPERIMENT_ID --output data/llm-evaluation/typed-extract.json
# После отдельной содержательной сверки по источнику и заполнения snapshot-bound review:
python scripts/evaluate_typed_facts.py --compare --experiment EXPERIMENT_ID --extraction data/llm-evaluation/typed-extract.json --review data/llm-evaluation/typed-review.json --output data/llm-evaluation/typed-compare.json
```

`EXPERIMENT_ID` берётся из prepare. Формат review аналогичен [SOURCE_FIRST.md](SOURCE_FIRST.md); решение требуется по всем программно допустимым фактам/конфликтам каждого неотклонённого случая. Модель не создаёт такое решение сама. Не присваивать статус специалиста. Подготовленные значения не становятся verified наблюдениями.

Нужны ignored `data/` с прежними raw-run и checkpoint, установленные веса и runtime. Полные запросы/ответы находятся в `data/wiki_updates/typed_fact_inputs/` и `typed_fact_runs/`, manifest — в `typed_fact_experiments/`, промежуточные решения — в `typed_fact_reviews/`. Черновики остаются в отдельном `source_first_drafts/`, не в Wiki. Маркеры попыток ограничивают опыт четырьмя вызовами, без повторов после ошибки. Последующая ручная редактура и научная рецензия остаются самостоятельными действиями.

## Последующее исправление упаковки контекста

Реальные генерации использовали код снимка `4fe1c06`; исходный протокол/ответы сохранены. После усечения второго этапа добавлены lossless-дедупликация цитат, фильтр замечаний к отклонённым ID, нативная проверка бюджета до генерации и числовая привязка reason к собственному факту. Нативная диагностика без генераций подтвердила уменьшение 7597→4808 токенов; новый ответ модели не запрашивался. Результативность новизны после исправления пока неизвестна. Для отдельного будущего протокола одного сравнения нужно явно связать уже проверенный пакет со следующим manifest; автоматический перенос между manifest сейчас запрещён.
