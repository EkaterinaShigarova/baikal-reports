# Протокол source-first: два случая, не более четырёх запросов

Зафиксирован до генераций, исходный commit `f16be21`, 22.10.2026. Экспериментальный режим; автоматизированная сверка не является научной экспертизой. Публикаций и новых verified наблюдений не будет.

## Неизменные условия

Использовать Qwen2.5-7B-Instruct Q4_K_M, оба прежних SHA256, прежний AVX2 llama.cpp, CPU 4 потока, контекст 8192, batch 256, один слот, temperature=0, max_tokens=1800, timeout=600 с, только loopback. Не скачивать/не пересобирать. Сохранить в точности source_fragments и Wiki-контекст двух v2-запросов из `datasets/llm_7b_comparison.json`, проверив хеши исходных записей, страниц и текущих статей. Источники: 2016/PDF 222 и 2015/PDF 26. Не добавлять новые доказательства или эталонные ответы в модельные входы.

## Порядок и граница проверки

1. Два source-only запроса: только прежние фрагменты с их метаданными, без статьи, known_issues и ожидаемых ответов. До шести атомарных фактов на случай: текст, evidence_ids, год наблюдения или null, показатель/единица/территория или null, тип сообщения, ограничения. Отдельно возможные противоречия фрагментов. Цитаты подставляет программа по неизменным ID.
2. Проверить схему, ID, числовые токены, явное основание года, точные локальные цитаты и версии. Числа должны присутствовать в выбранных цитатах, не только в метаданных отчёта. Ошибочные записи отвергать отдельно, без исправления вывода. Это ещё не проверка смысловой поддержки.
3. Обязательная отдельная сверка каждого оставшегося факта/конфликта с источником: решение support/reject, причина, ограничения, привязка к SHA256 пакета и fact-ID. Не разрешать перенос неподдержанного тезиса на этап 2. Сверка не даёт статуса специалиста или проверенного числового наблюдения; исходный факт нельзя переписать.
4. Не более одного сравнения на случай, только если остались поддержанные факты. Передать эти неизменные факты, их ID/цитаты, прежнюю статью и известные вопросы. Ответ: решение по каждому ID (`already_present`, `new_detail`, `contradiction`, `insufficient_evidence`), точный фрагмент статьи для повтора/противоречия, обоснование и ограничения. Запретить поля с переписанным фактом/источником, неизвестные ID и неполный охват фактов. Дополнение строит программа из исходного факта, только как неопубликованный черновик для редакционного разбора. Смысловая правильность новизны проверяется отдельно.

Лимит — четыре попытки HTTP генерации, по одной на комбинацию случай/этап; неиспользованный запрос не переносится другому случаю. Ошибки/отклонения не исправлять повторной генерацией. Попытку записывать до HTTP и запрещать повтор с тем же manifest. Если этап 1 не пройден, этап 2 пропустить и явно отразить это. Допускаются два запуска того же сервера для остановки между извлечением и проверкой; отдельно учитывать их старт/завершение и не приписывать время редакционной сверки модели.

## Критерии до запуска

- Считать раздельно записи модели, программно допустимые факты, смыслово поддержанные факты и атомарность. Корректный JSON не считать научным результатом.
- Проверить факт о выпуске 1029 тыс. рыб средней навеской 3,0 г как часть 1044 тыс.; не превращать выпуск в выживаемость или восстановление запасов. Не подставлять год отчёта как год наблюдения без явного основания выбранной цитаты.
- Проверить множитель 2,7 для канцерогенных аренов 2015 относительно 2014 как авторское сообщение; это отсутствующая в статье деталь, не независимо пересчитанный показатель/сопоставимый ряд.
- Проверить сохранение неоднозначности порядка БП/канцерогенов в прозе и таблице 2015. Не переставлять значения произвольно. Отдельно учитывать, обнаружена ли проблема без Wiki и сохранена ли после сравнения с Wiki.
- Проверить атрибуцию каждого существенного утверждения, единицы, территорию, годы, отсутствие вымышленных значений/причинности, неподдержанных противоречий и неверной новизны. Нулевой ответ не является содержательным дополнением.
- Новая деталь пригодна для редакционной проверки, только если поддержана источником, отсутствует в статье, содержит необходимые ограничения и сохраняет относящееся противоречие. Это не редакционное одобрение и не научная рецензия.
- Сравнить с 1.5B v2 и 7B v2: число claim/fact-блоков, поддержка, атрибуция, новизна, противоречия, полезные черновики, время и RSS. Единицы подсчёта и наличие отдельной промежуточной сверки различаются; нельзя приписать весь эффект только модели или получить общую оценку точности по двум случаям.

## Воспроизводимость и сохранность

Сохранить неизменный manifest, SHA256 протокола/промптов/модели/runtime/источников/статей, фактические запросы и сырые ответы, решения промежуточной сверки, отклонённые записи и причины. Большие файлы/полные raw-ответы остаются в ignored data; публичный отчёт содержит компактные результаты и хеши. Контроль: 22 статьи, 168 наблюдений, научные реестры, прежние отчёты, размер/mtime 3878 checkpoint и SHA256 11 PDF. Сайт, OCR и внешние модельные сервисы не используются.
