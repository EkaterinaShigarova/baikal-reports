# Необязательный семантический синтез

Обработка PDF, OCR, Wiki с выдержками, поиск и графики не требуют LLM API. Команда `python -m baikal synthesize air` включает дополнительный синтез ограниченного пакета доказательств (до 12 выдержек, максимум 1800 токенов ответа).

Бесплатный локальный вариант: установить Ollama отдельно, загрузить подходящую модель, например qwen2.5:7b; задать `BAIKAL_LLM_URL=http://127.0.0.1:11434/v1/chat/completions` и `BAIKAL_LLM_MODEL=qwen2.5:7b`. Требуются память/диск для выбранной модели; установка модели не выполнена в облачной проверке. Файл .env автоматически не читается: экспортировать переменные через терминал или настройки запуска VS Code.

Можно использовать совместимый HTTPS API с `BAIKAL_LLM_API_KEY`. Это передаёт выбранные публичные выдержки провайдеру. Точная стоимость зависит от выбранного провайдера и модели: `(input_tokens × input_price + output_tokens × output_price) / 1_000_000` для тарифов за миллион токенов. Тарифы не фиксируются и не выдумываются; перед включением сверить их у провайдера. По умолчанию вызовов и расходов нет.

Ответ принимается только как JSON с точными ссылками на переданные source_id/page и подстроками цитат. Неподтверждённые ссылки отклоняются. Выход сохраняется как **черновик**, потому что наличие цитаты ещё не доказывает, что она логически поддерживает утверждение. Автоматического повышения статуса числовых наблюдений нет. Проверка валидатора выполняется тестами; реальный вызов LLM требует настроенного сервера и отдельно не заявляется как проверенный.
