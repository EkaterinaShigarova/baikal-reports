# Необязательный семантический синтез

Обработка PDF, OCR, Wiki с выдержками, поиск и графики не требуют LLM API. Команда `python -m baikal synthesize air` включает дополнительный синтез ограниченного пакета доказательств (до 12 выдержек, максимум 1800 токенов ответа).

Бесплатный локальный вариант: установить Ollama отдельно, загрузить подходящую модель, например qwen2.5:7b; задать `BAIKAL_LLM_URL=http://127.0.0.1:11434/v1/chat/completions` и `BAIKAL_LLM_MODEL=qwen2.5:7b`. Требуются память/диск для выбранной модели; установка модели не выполнена в облачной проверке. Файл .env автоматически не читается: экспортировать переменные через терминал или настройки запуска VS Code.

После отдельного согласия пользователя можно использовать совместимый HTTPS API с `BAIKAL_LLM_API_KEY`. Это передаёт выбранные публичные выдержки провайдеру. Точная стоимость зависит от выбранного провайдера и модели: `(input_tokens × input_price + output_tokens × output_price) / 1_000_000` для тарифов за миллион токенов. Тарифы не фиксируются и не выдумываются; перед включением сверить их у провайдера. По умолчанию вызовов и расходов нет. Удалённый URL программно блокируется без явного флага `--allow-remote`; его включение требует отдельного согласия пользователя. Перенаправления запрещены, чтобы локальный сервер не перенаправил запрос во внешний сервис.

Ответ принимается только как JSON с точными ссылками на переданные source_id/page и подстроками цитат. Неподтверждённые ссылки отклоняются. Выход сохраняется как **неопубликованный черновик** в ignored `data/wiki_updates/llm_drafts/`, потому что наличие цитаты ещё не доказывает, что она логически поддерживает утверждение. Автоматического повышения статуса числовых наблюдений нет. В тестах проверены валидатор, блокировка удалённого вызова и весь HTTP-путь на локальном тестовом сервере с фиксированным ответом. Это проверка интеграции, не работы настоящей языковой модели. В отдельном ограниченном опыте уже получены два настоящих ответа локальной Qwen; оба отклонены. Внешние модельные API не использовались. Подробности: [LLM_EVALUATION.md](LLM_EVALUATION.md).

В спринте энциклопедии 14 новых статей подготовлены на основе выбранных сохранённых страниц. Платный API и локальный модельный сервер не запускались. Находящиеся в Git статьи и их основания можно читать без LLM; для дальнейшей автоматической генерации сохраняется описанный выше отдельный режим черновиков и проверки.


## Предложения по обновлению

Рекомендуемый режим: `python -m baikal synthesize TOPIC_ID --proposal PROPOSAL_ID` после `propose-updates`. Пакет содержит до 12 точных фрагментов с версиями источников; перед запросом проверяются его целостность, актуальность и цитаты. Старый режим `synthesize air` по-прежнему использует короткие выдержки компилятора; они могут не представлять всё содержание темы и требуют отдельной оценки пригодности.

Команда больше не записывает модельные черновики в `wiki/syntheses/` и не обновляет каталог или наблюдения. Результат и предыдущие версии целевых статей сохраняются по контрольным суммам; разные ответы не перезаписывают друг друга. Публикация после содержательной проверки — отдельное редакционное действие.

Содержательная проверка существующей Wiki использует автоматизированный LLM-метод; её реестр не означает запуск встроенного локального сервера или экспертную рецензию. После разрешения CDN веса Qwen получены с проверкой SHA256. Прежний native backend завершился с SIGILL на CPU текущей среды; из тех же исходников llama.cpp v0.7.0 собран отдельный AVX2 runtime. Он выполнил два настоящих запроса, оба ответа отклонены проверкой цитат и ограничений. Статьи не изменены. Unit-тесты с синтетическими ответами проверяют транспорт и сохранность, а не качество модели. План настоящего теста и протокол опыта: [UPDATE_WORKFLOW.md](UPDATE_WORKFLOW.md).

## Оценка новизны относительно Wiki

`synthesize TOPIC_ID --proposal PROPOSAL_ID --assess-update` добавляет в запрос ограниченный основной текст текущей статьи, кандидаты каталога и известные проблемы. Заметки HUMAN NOTES не считаются проверенным контекстом. Ответ различает `new_detail`, `already_present`, `uncertain`, период наблюдения, ограничения и потенциальные противоречия. Для другой темы без её текста новизна должна оставаться неопределённой. Проверка этих полей — структурная, а не доказательство правильного понимания.

В ignored `data/wiki_updates/llm_inputs/` и `llm_runs/` сохраняются вход, сырой ответ, время, usage и ошибки, включая отклонённый JSON/цитаты. Ключи API и заголовки авторизации не сохраняются. Локальный клиент явно отключает HTTP-прокси и перенаправления, чтобы текст не покидал loopback через настройки среды. Изменившиеся за время генерации источники или статья блокируют принятие черновика.

Настоящий CPU-инференс Qwen2.5-1.5B-Instruct Q4_K_M проверен: два ответа за 178,140 с вместе со стартом сервера, пиковый дочерний RSS около 2,10 ГиБ. Допустимых черновиков — 0: изменённая цитата, неверная атрибуция текста Wiki и пустые ограничения. Воспроизводимый протокол и подробная оценка — [LLM_EVALUATION.md](LLM_EVALUATION.md). Проверка backend через `--list-devices` дополняет `--version` и выявляет несовместимый runtime до инференса. Синтетические тесты учитываются отдельно от двух реальных ответов.


## Протокол доказательств v2

Добавлен opt-in `--assessment-protocol v2` вместе с `--assess-update`: модель выбирает evidence_ids из первичных фрагментов, программа связывает их с исходными цитатами и сохраняет тот же строгий контракт черновика. Wiki-контекст не может служить первичным доказательством. Неизвестные ID, подмена цитаты, заголовки и очевидные повторы с меткой нового, отсутствующие в доказательстве числа и пустые ограничения блокируются. Числовая проверка не заменяет проверки единиц/территории/метода, а точная цитата не доказывает её логической поддержки.

Повтор на той же 1.5B дал ещё два реальных ответа, оба отклонены: пригодных обновлений 0, смысловое качество не улучшилось. Контроль простого JSON отдельно показал ошибку типа числа. Qwen2.5-7B Q4_K_M рассматривается только как кандидат для отдельного сравнения: Apache-2.0, два файла 4,36 ГиБ, оценочно 12–16 ГиБ RAM; не скачивалась и не запускалась. Нужны ограниченная поддержка shard/SHA256 и одинаковые входы; текущая защита 2 ГиБ не отключается. Полный разбор: [LLM_EVALUATION.md](LLM_EVALUATION.md).
