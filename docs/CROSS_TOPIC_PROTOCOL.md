# Протокол переноса реестров на две темы

Исходный commit 421df70. До запуска зафиксированы источники, SHA256 статей, реестр 27 атомарных сообщений и 12 эталонных сравнений. Действующие статьи, старые опыты и observations не меняются. Планы/прогнозы не подставляются вместо наблюдений; отсутствие этих типов в выбранных карточках не означает отсутствия в коллекции.

Выбор: нерпа (13 сообщений) и качество воды (14). Есть несколько докладов, точные подтверждения, разные объекты, нормативы, неопределённости и нерешённые методические вопросы. Охват считается по абзацам/табличным блокам, **не сравнивается с прежним процентом предложений Селенги**, не означает полную атомизацию. Методический контекст и состояние проекта учитываются отдельно; рецензия специалиста не присваивается.

Сначала программная маршрутизация. Различие/неизвестность методик не является доказательством их принципиальной несовместимости. Только T11 допускается передать установленной Qwen 7B: **не более одного нового запроса**, максимум 2500 входных токенов, 256 выходных, полный резерв и нативная проверка бюджета; прежний runtime, CPU4/context8192/GPU0, temperature0, timeout600с. Без загрузки модели, внешних API, повторов и ремонта ответа. В ответе только привязанные ID и entails/not_entailed/uncertain, без переписывания фактов. Одного JSON недостаточно; нужна отдельная содержательная сверка результата.

Оценивать отдельно 11 структурных решений и одну модельную интерпретацию. Это отобранные, предварительно структурированные случаи, не слепая оценка свободного извлечения. Предыдущие три запроса и V07 не повторяются; прирост общей точности по сравнению с прежними наборами не рассчитывается.

Глобальное отсутствие T02 проверяется отдельно по всей точной версии статьи, включая блоки без карточек, и по хешу конкретного факта. Только доказательный кандидат, не публикация, не human approval, не новая строка observations. Пять/семь сохраняются без выбора истинного значения. Если доказанного междокладного конфликта сопоставимых измерений установить нельзя, это незавершённая научная задача, а не повод выдумать положительный пример.

Проверить все старые материалы и checksum, 22 статьи, 168 наблюдений, 3878 checkpoint и 11 PDF. Сырые ответы/веса и архивы остаются в ignored data. В публичном отчёте сохранять точные цитаты, источники, страницы, годы, ограничения и причины решений. Результаты не объявлять научной экспертизой.
