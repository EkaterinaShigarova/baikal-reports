# Предварительный протокол обнаружения тем от f57c375

Протокол и набор задач фиксируются до реального запуска Qwen. Не повторять запрос после ошибки ради улучшения счётчика. Максимум **четыре** настоящих запроса, по одному на задачу. Модель и runtime прежние; CPU, температура 0, контекст 8192, ответ до 950 токенов. Никаких загрузок PDF, OCR, внешних запросов с текстами или публикации.

## Входы и эталоны

[Набор задач](../datasets/topic_discovery_tasks.json) использует точные ранее сверенные выдержки, ID/SHA256 и физические страницы. Это отобранный исследовательский набор, не независимая случайная выборка и не свободное извлечение фактов моделью. Поля expected/expected_basis фиксируются заранее и **не передаются модели**. Старые полноценные черновики не передаются Qwen и не переписываются.

| Задача | Область | Ожидаемая рекомендация | Проверяемая граница |
| --- | --- | --- | --- |
| D01 | Порты, вода и нефтепродукты | Новая отдельная статья | Три документа; очередь ports-oil не равна опубликованной статье; фон, норма и отдельные вещества различаются |
| D02 | Коммунальный сброс, оператор и мониторинг | Новая узкая статья с перекрытием | bcbk-legacy уже содержит общие сведения; статья о воде — контроль. Все эти сведения нельзя объявить новыми; обе версии фенолов обязательны |
| D03 | Нерпа, береговое обследование и учёт | Дополнение baikal-seal | Общий объект уже есть; не создавать дубликат, разделять даты эпизода и обследования |
| D04 | Эффективность очистки | Отложить | Один объём воды не подтверждает удаление загрязняющих веществ |

D02 — редакционная гипотеза разделения предметов, а не единственный научно возможный способ организации. Отличающийся ответ отдельно объясняется; эталон после генерации не меняется. Для D03 отсутствие детали подтверждено прежним полным разбором версии статьи; общий механизм не наследует эту проверку для других фактов.

## Что оценивается раздельно

1. Решение и target_id совпадают с заранее записанным эталоном.
2. Выбраны существенные evidence-ID из expected, источники не придуманы. Цитаты подставляются программой, а не сочиняются моделью.
3. Отношение к показанным статьям смыслово обосновано; общий термин не заменяет различения предметов. Частичные блоки **не доказывают отсутствия факта во всей Wiki**.
4. План структурирован, относящиеся к нему фрагменты релевантны. Корректность JSON оценивается отдельно от научной полезности плана.
5. Все обязательные ограничения сохранены; нет неподдержанных чисел, причин и тенденций в свободном названии/объяснении.

Кандидат для редактора допустим только после отдельной содержательной сверки этих пунктов. Прохождение программного gate само по себе не засчитывается как достоверное предложение. Человеческого одобрения и экспертного статуса нет.

## Воспроизводимость и ограничения

Манифест закрепляет SHA256 протокола, набора, программы, каталога, реестра источников, версий релевантных статей, полный prompt и wire-контекст. Один эксперимент резервирует весь лимит до первого запроса; падение не разрешает повтор. Сырые ответы, запросы, ошибки, время и точные входы сохраняются в ignored data/wiki_updates; компактный публичный отчёт содержит хеши, решения и причины сверки. Предыдущие статьи со всеми заметками архивируются существующим archive_article; события сохраняются существующим save_packet.

Отдельный read-only scan всех готовых checkpoint ищет повторяющиеся нумерованные заголовки разных документов. Это только тематические зацепки без статуса научного факта/новизны. Разметка переносов, ненумерованные заголовки и разное написание ограничивают полноту. После scan пока требуется отбор и проверка доказательного пакета; автоматического перехода от любого заголовка к готовой научной статье нет.

Подбор контекста использует названия, совпадения страниц источников и точные блоки статей; внутренние связи передаются отдельно. Лексический поиск здесь только сокращает контекст. Смысловое решение даёт модель, программные границы и последующая проверка, а не совпадение слов. Две релевантные статьи не гарантируют полный поиск дубликатов. После предварительного подсчёта токенов без генерации исключены лишние статьи и повторяющиеся метаданные каталога; таблицы сохранены точными непрерывными выдержками со своими заголовками и годами столбцов, без перестановки ячеек.

Генератор сохраняет **доказательный план Markdown с неизменными цитатами**, ограничениями, версиями связанных статей и физическими страницами PDF. Он не объявляется полноценным аналитическим синтезом. Два существующих связных черновика служат внешними проверочными примерами; успешная структура не доказывает способность автоматически написать их с тем же качеством.
