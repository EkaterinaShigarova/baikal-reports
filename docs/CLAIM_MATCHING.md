# Сравнение по структурированному реестру утверждений

Экспериментальный режим, 23.10.2026. [Протокол до запуска](CLAIM_MATCHING_PROTOCOL.md), [реестр](../datasets/selenga_claim_registry.json), [контрольный набор](../datasets/claim_comparison_benchmark.json), [итоговый отчёт](../datasets/claim_matching_evaluation.json). Автоматизированная сверка не является научной рецензией специалистом.

## Реестр и границы сравнения

Выбрана статья [об авандельте Селенги](../wiki/syntheses/selenga-sediments.md). Семь записей описывают только её сообщения об ароматических загрязнителях 2015 года. Каждая запись связана с полным SHA256 статьи, точным текстом и его позициями; источники связаны с ID, SHA256 PDF, физической страницей, неизменной цитатой и ролью прозы/таблицы. Для таблицы сохранены ссылки на ранее проверенные столбцы. Изменение статьи, цитаты, ячейки или источника делает проверку устаревшей, а не обновляет хеш автоматически.

Поля `features` задают объект, показатель, числовое или качественное значение, единицу, территорию, период наблюдения, статистику, тип сообщения, область сводки и атрибуцию. Качественные оценки имеют `value: null` и `unit: null`: это отсутствие числового показателя, а не ноль. Неизвестный период остаётся null; год доклада не подставляется. `statement_kind` различает наблюдение, авторскую оценку, план и прогноз. В этом узком наборе планов/прогнозов нет; их разделение проверено отдельными синтетическими отрицательными unit-тестами, а не объявлено измеренным качеством модели.

Максимумы записаны как **сообщения сводки доклада**, с областью авандельты. Это не выдуманные координаты станции или одинаковая физическая выборка. Реестр не разрешает сравнение разных сред/территорий или построение временного ряда. Неизвестная публикация и статус mirror_unverified сохранены.

## Маршрутизация

Строгое совпадение признаков/значения/атрибуции даёт сигнал имеющейся записи. Уже описанная противоположная версия не отменяет наличие самого варианта: при полной области поиска повтор имеет приоритет. Для намеренно выбранной пары прозы и таблицы выдаётся документированное расхождение атрибуции. Произвольные разные числа при похожих словах не признаются противоречием автоматически.

Неизвестный существенный признак или попытка назвать один спорный максимум истинным останавливают сравнение без модели. Отсутствие совпадения выдаёт `llm_required`, а не new_detail. Такой вывод не доказывает отсутствие словесного эквивалента в статье, тем более в остальной Wiki.

Qwen получает один неизменный факт, компактное доказательство, релевантные содержательные утверждения и открытые вопросы. У неё нет поля для переписывания чисел/источников или свободных научных выводов. Ответ выбирает категорию, код отношения и допустимые ID; заголовки не входят в реестр доказательных утверждений. Класс и код должны согласовываться. Даже полный ответ остаётся непроверенным предложением до отдельной смысловой сверки.

## Что именно проверяет набор

Восемь сравнений: по два повтора, новых деталей, противоречий и недостаточных сведений. Это не восемь независимых экологических измерений. Два противоречия — уже описанная перестановка максимумов БП/канцерогенных аренов в источнике. Они сравниваются с конкретной противоположной записью статьи; это **не новые противоречия Wiki**. Один факт участвует в двух разных областях сравнения. Один отрицательный пример — явно обозначенная неполная проекция настоящей цитаты с пропущенным периодом. Второй проверяет невозможность выбора истинного значения при конфликте источника.

Две новые детали — прежние source-checked средние 2,1 и 36,9; они не извлекались заново. Их отсутствие проверяется по полной статье отдельно от частичного реестра. Третий старый факт 61,7 сохранён, но не тестируется в этом сбалансированном наборе. Старый подход сравнивается только на двух общих случаях, для остальных шести старых ответов нет.

## Воспроизведение в подготовленной среде

Из корня проекта в установленном окружении Python:

```bash
python scripts/evaluate_claim_matching.py --help
python scripts/check_claim_matching.py --require-local
python scripts/evaluate_claim_matching.py --prepare --output data/llm-evaluation/claim-comparison-prepared-3ce5604.json
python scripts/evaluate_claim_matching.py --run --experiment 564fdf6b83120ba4f8952b8933525972f72286444aa19f49c8cf2687e3c374c4 --output data/llm-evaluation/claim-comparison-run-3ce5604.json
```

Подготовка не вызывает модель. Протокол, код, реестр и эталоны зафиксированы в commit `ed40345` до генераций; manifest сохраняет их SHA256 и маршруты. Пять случаев обрабатывает программа; только A2/N1/N2 получают по одному реальному запросу. Повтор использованной попытки и перезапись существующего выходного файла запрещены. Для нового исследования нужен новый протокол, а не обход этого ограничения.

Для запуска нужны уже установленные веса Qwen 7B, прежний llama.cpp и локальные контрольные точки. Загрузка весов/пересборка/OCR не выполняются. В публичной копии без `data/` проверка без `--require-local` проверяет сохранённые реестры и отчёт, но не притворяется чтением отсутствующих журналов модели. Нативный бюджет ограничен 3500 входными токенами плюс полным резервом ответа; все обращения только к собственному 127.0.0.1 без внешнего API.

## Неопубликованные кандидаты

После каждого действительного ответа требуется отдельная смысловая сверка с причинами и хешем ответа. Только поддержанные new_detail могут быть сохранены функцией `baikal.claim_candidates.save_candidates`. Она повторно проверяет версии статьи/источников, сохраняет **исходный** ранее проверенный факт и полную предыдущую статью с заметками в ignored data. Синтетические решения допустимы только в изолированных тестах; в настоящем репозитории запрещены.

Кандидат не является редакционным одобрением, обновлённой статьёй, экспертно подтверждённым измерением или новой строкой observations. В старом тексте фактов слово «среднее» пропущено, хотя statistic=mean и ограничения его явно задают. Перед публикацией нужна ясная редакционная формулировка, сохраняющая исходные значения, территорию, период и неопределённости. Автоматического моста к публикации нет.

## Результат ограниченного запуска

Проверены восемь сравнений: **5 правильных, 3 неправильных/отклонённых**. Структурная часть решила свои пять случаев верно. Qwen выполнила три полных запроса и не помогла ни одному: A2 выдала new_detail одновременно с кодом same_scoped_statement; оба средних N1/N2 снова названы insufficient_evidence. Правильный частичный код A2 не использовался для исправления ответа.

Все три ответа отдельно проверены и отклонены в указанном объёме. Функция сохранения кандидатов проверена на этих действительных отклонённых результатах и вернула None: кандидатов **0**. Положительная запись кандидатов проверена только в изолированных синтетических тестах; успешного реального пути с допущенным ответом пока нет. Три старых факта, статьи, наблюдения и контрольные точки сохранены.

Точный источник: [доклад 2015, PDF 26](../wiki/sources/drive-1FFG7dMsfKpCRp3yWVm8m2C9vjxK8ATab.md#page-26). Подробные решения, сообщения об отказах, версии и контрольные суммы находятся в отчёте. Новизна N1/N2 была подтверждена отдельной сверкой полной статьи до запуска, но модель не выделила её. Ни пять структурных успехов, ни восемь узких зависимых примеров не доказывают общую точность Wiki/LLM.
