# Baikal LLM Wiki: воспроизводимая коллекция, знания и экологические данные

Проект превращает реальные PDF в постоянную связанную Wiki, проверяемые наборы данных и локальный исследовательский интерфейс. Исходные файлы сохраняются по SHA256, страницы обрабатываются с контрольными точками; числовые кандидаты отделены от reviewed наблюдений.

Обработаны все 10 PDF Drive за 2015–2024 годы (3651 страница) и официальный обзор Росгидромета за 2025 год (227 страниц), всего 3878 страниц. В Git включены код, 168 сверенных значений с происхождением, 22 аналитические статьи и компактные отчёты. PDF, SQLite, изображения и секреты исключены. Исходные файлы и предыдущие 49 значений сохранены.

Добавлены аудит возможной потери столбцов, OCR rus+eng, поиск FTS, обновление тематических страниц и контроль версии источников статей. Веб-интерфейс поддерживает фильтр годов/территорий, сопоставимые ряды, Wiki, просмотр страниц и предупреждения качества. Платные LLM не вызываются без отдельного разрешения; интеграция проверена на локальном тестовом сервере.

Проверки: 36/36 unittest без пропусков; Wiki lint без ошибок; Ruff F; SHA256 и непрерывность 3878 страниц; 168 точных цитат проверены по локальным страницам; Chromium проверил фильтры, графики, запрет несопоставимых сравнений, Wiki-таблицы, поиск, столбец «сентябрь» и мобильную ширину без ошибок JavaScript.

Ограничения: 882 таблицы помечены эвристическим аудитом для проверки; полная научная оцифровка графиков/карт и экспертная валидация всех данных не завершены. Официально подтверждён обзор Росгидромета; зеркала десяти специализированных докладов требуют сопоставления с официальной публикацией. Наличие специализированных докладов за 2003–2014 и 2025–2026 не установлено. Подробности: PROGRESS.md, SOURCES.md, docs/QUALITY.md и docs/REMAINING.md.

Спринт энциклопедии добавил 14 статей по всем годам 2015–2025, иерархию из шести разделов/15 подтем, поиск по текстам статей и устойчивые внутренние адреса. 67 новых ссылок сверены с 46 содержательными страницами 11 документов. Все 3878 готовых контрольных точек и 168 reviewed наблюдений сохранены без изменений.
