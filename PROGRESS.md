- Созданы PLAN.md, AGENTS.md, .gitignore и структура проекта.

## Этапы 1–5 — реализация и первая реальная обработка
- Оригинальный gist Karpathy получен и прочитан после изменения доступности сети; соответствие описано в docs/METHODOLOGY.md.
- Готовы CLI, потоковая загрузка и SHA256, постраничные JSON/Markdown/HTML, таблицы двух движков, изображения/превью, OCR rus+eng, возобновление и отчёты QA.
- Готовы SQLite FTS, постоянные страницы Wiki, индекс/журнал, ingest/query/lint и необязательный LLM-синтез с проверкой цитат.
- Создан набор 49 значений, сверенных с текстом и изображениями таблиц доклада 2018 года. Сопоставимость серы не утверждается; разрешены только внутритабличные ряды выбросов.
- Веб-приложение запускается; API источников, Wiki, страниц и рядов вернул HTTP 200.
- Первые 10 автоматизированных тестов прошли. Расширяются проверки API и браузера.
- Коллекция обрабатывается последовательно, промежуточные данные сохранены локально. Официальные сайты: часть отвечает 503, Росгидромет — 200; дополнительные PDF пока не подтверждены.

## Этап 6 — проверка интерфейса и устойчивости
- Браузер Chromium: обзор, семь точек годового графика, сравнение лет, блокировка несопоставимого ряда, поиск, переход к странице, Wiki и мобильная ширина. Ошибок JavaScript нет.
- Обнаружена и исправлена потеря OCR-результата из-за отсутствующего TSV-конфига в отдельном tessdata. Добавлена проверка формата TSV и тест растровой страницы. Ограничен OpenMP-параллелизм Tesseract; затронутые страницы пересчитаны.
- Проверено возобновление: первая страница не переписывается, недостающая обрабатывается. Чистый Git-клон без raw не стирает сохранённую Wiki.
- Созданы requirements.lock, README для VS Code и экспорт числовых кандидатов. Сложные таблицы и графика остаются явно помеченными для проверки.
- Добавлен безопасный разбор подтверждения Google Drive для больших файлов. Скачивание двух самых больших документов выполняется отдельно от обработки; результаты сохраняются по SHA256.
- Скрипты install_script/start_skill сохранены в черновик среды; это не публикация новой версии.
