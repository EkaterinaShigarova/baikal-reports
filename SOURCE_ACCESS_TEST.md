## Загрузка и программное чтение

Выбран файл «Доклад Байкал за 2018 год.pdf», ID `1QKhC57MB-qveIXhYWKGfSOkTmzdFw_mJ`.

Фактически выполненная команда (повторная загрузка перезаписывает только локальный файл проверки):

```bash
mkdir -p /tmp/baikal-source-recheck
curl --location --max-time 120 --silent --show-error \
  --dump-header /tmp/baikal-source-recheck/pdf.headers \
  --output /tmp/baikal-source-recheck/sample.pdf \
  --write-out 'HTTP %{http_code}; bytes %{size_download}; final %{url_effective}\n' \
  'https://drive.usercontent.google.com/download?id=1QKhC57MB-qveIXhYWKGfSOkTmzdFw_mJ&export=download'
```

Результат: HTTP 200, код завершения 0, 8 079 399 байт; конечный URL совпал с указанным. Сигнатура файла `%PDF-1.6`, размер совпал с метаданными папки. Файл успешно открыт PyMuPDF и pdfplumber; пароль не потребовался.
